# Six reusable slide specimens

Open `gallery.html` from a local clone in a browser. GitHub's file view shows source code rather than rendering the gallery. Use **Print / save PDF** for the six-page layout reference; enable background graphics in browsers that require it.

The gallery demonstrates:

1. A typographic opening with a learning promise.
2. A large source-figure slot with an opt-in original ReAct exhibit.
3. Editable illustrative code with input/execution/verification explanations.
4. A zero-baseline result chart using clearly labeled synthetic values.
5. An illustrative baseline/candidate prompt comparison and release gate.
6. A closing research question linked to the talk's evidence.

These are original, brand-neutral HTML/CSS examples, not copies of the private reference presentation. No font binaries or third-party image bytes are bundled. The second slide loads the public ReAct figure only after its button is clicked; no external assets load automatically. If unavailable, the source link and clearly labeled slot remain. Check reuse terms before redistribution.

The default print export contains the source-figure slot rather than a downloaded figure. Load the figure before printing when authorized and available. All other examples work offline. The gallery's chart values are synthetic, its code is pseudocode, and its candidate prompt has no measured result.

The HTML content and CSS are editable; a printed PDF is not an editable Google Slides presentation. Use these layouts with the skill's [design recipes](../references/design.md) and [slide specification](../assets/slide-spec.json) to author native text and objects in your chosen presentation tool. Inspect the actual target export again after conversion.
