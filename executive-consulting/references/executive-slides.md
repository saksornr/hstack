# Executive slides

## Storyboard contract

For each slide specify:
1. Message title: one substantive claim or decision.
2. Executive question answered.
3. Evidence: exact data/source, calculation, or explicit evidence gap.
4. Exhibit: layout and visual encoding.
5. Implication or decision.
6. Speaker note: caveat, nuance, or anticipated objection.

For a short decision deck, a useful sequence is:
- Executive summary and ask.
- Baseline and why action matters now.
- Diagnosis and evidence.
- Options and recommended choice.
- Proposed value case and assumptions.
- Strategic Roadmap, owners, and gates.
- Decision, resources, and immediate next step.

Merge or expand to fit the request. Move supporting methods, sensitivity tables, and detailed evidence to an appendix. Do not make an agenda page mandatory for a short deck.

## Choose the exhibit by the claim

| Purpose | Exhibit | Integrity requirement |
| --- | --- | --- |
| Compare magnitudes | Sorted bars or dots | Consistent units; zero baseline for bars |
| Show change over time | Line chart | Consistent intervals and defined period |
| Explain additive change | Waterfall | Start + signed components = end; disclose decomposition convention |
| Show customer behavior | Cohort table or curve | Explicit cohorts and denominator; comparable observation windows |
| Compare choices | Options table | Same criteria and visible trade-offs |
| Prioritize qualitatively | 2×2 | Defined axes; avoid unsupported exact placement |
| Relate three quantitative measures | Bubble chart | Label axes and size variable; scale bubble area, not radius |
| Show work and accountability | Roadmap or swimlane | Owners, milestones, dependencies, gates |
| Explain genuine dependencies | Process or system diagram | Every arrow represents a named relationship |

Use a table or a labeled hypothesis tree when data is missing. Do not substitute made-up charts. Distinguish actual, target, forecast, and illustrative series visually and in text.

## Layout defaults

Respect the supplied template. For a new 16:9 deck, a practical starting point is:
- 0.4–0.6 inch outer margins; shared title and footer anchors.
- Titles around 28–34 pt, body around 18–24 pt, sources around 10–12 pt, adjusted for viewing distance.
- One compatible font family, or at most two. For Thai, use an available Thai-capable font such as Noto Sans Thai or Sarabun and verify glyph rendering and line breaks.
- Dark text, light background, one primary accent; semantic colors used consistently.
- One dominant exhibit with a concise implication; put detail in notes or appendix.
- Repeated box sizes, equal gutters, consistent internal padding, aligned edges.
- Restrained borders and fills. Avoid decorative shadows, 3D charts, and icon clutter.

These are starting points, not a reason to override the user's brand. Never solve overflow by making the whole slide unreadably small. Shorten, split, or move supporting detail.

## Executive audience tuning

- CEO: strategic choice, enterprise trade-offs, execution accountability.
- CFO: baseline, incremental economics, cash timing, assumptions, downside.
- COO: capacity, process bottlenecks, handoffs, service levels, implementation.
- Board: material decisions, strategic alternatives, risk, governance.
- Functional leadership: concrete actions, dependencies, resources, measures.

Tailor emphasis to the actual mandate rather than assuming everyone with the same title wants the same deck.

## Export and QA

Create native editable text, shapes, tables, and charts where feasible. Use raster visuals only when they serve the content; do not flatten an entire editable deck into screenshots.

Render the exported file, not only an HTML preview. Inspect every slide for clipping, overflow, alignment, contrast, chart labels, font substitution, Thai shaping, page numbers, and source readability. Check notes and hidden content for unintended draft material. Reconcile headline numbers with exhibits and summary.

When PDF is requested, inspect its rendered pages too. Deliver only the formats requested or clearly useful to the task. State honestly if the environment could not export or inspect a format.
